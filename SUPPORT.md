# Getting help

- **Data API reference**: [shopsavvy.com/data/documentation](https://shopsavvy.com/data/documentation), including every [error code](https://shopsavvy.com/data/documentation/errors) and its fix
- **OpenAPI spec**: [api.shopsavvy.com/v1/openapi.json](https://api.shopsavvy.com/v1/openapi.json)
- **MCP server setup** for each AI client: [shopsavvy.com/agents](https://shopsavvy.com/agents#install)
- **Questions and ideas**: [Discussions on shopsavvy-mcp-server](https://github.com/shopsavvy/shopsavvy-mcp-server/discussions)
- **Bugs in an SDK or integration**: open an issue in that repository
- **Account, billing or API key problems**: support@shopsavvy.com (include the `request_id` from the API response)
- **Security issues**: see [SECURITY.md](SECURITY.md); do not open a public issue
