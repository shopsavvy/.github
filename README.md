# shopsavvy/.github

Organization-wide defaults for the [ShopSavvy GitHub organization](https://github.com/shopsavvy):

- `profile/README.md`: the organization profile shown at github.com/shopsavvy
- `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`: default community health files for every repository that doesn't have its own
- `.github/ISSUE_TEMPLATE/` and `.github/pull_request_template.md`: default issue forms and pull request template

Facts and numbers in the profile follow ShopSavvy's enterprise facts ledger (tens of thousands of retailers, price history back to 2011 and dense from 2019, 10 SDKs). Update them together.
